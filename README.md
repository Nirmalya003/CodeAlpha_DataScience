## 📌 Projects

### 1. Iris Flower Classification

**Folder:** `Task-1-Iris-Classification`

This project focuses on classifying Iris flowers into three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The model uses flower measurements such as:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

#### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

#### Key Steps

1. Data loading
2. Data exploration
3. Data preprocessing
4. Exploratory Data Analysis
5. Feature selection
6. Machine Learning model training
7. Model evaluation
8. Accuracy analysis
